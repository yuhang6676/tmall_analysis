# 天猫订单数据分析项目

基于天猫订单数据，使用 Python（Pandas + Pyecharts）对成交金额、退款金额在**时间维度**和**地区维度**上进行多维度分析与可视化。

## 技术栈

- **Python 3** — 数据处理与分析
- **Pandas** — 数据清洗、聚合、时间特征提取
- **Pyecharts** — 交互式可视化（折线图、柱状图、中国地图）
- **Matplotlib / Seaborn** — 概率密度分布图（KDE）

## 数据概览

- **数据来源**：天猫订单报表（`tmall_order_report.csv`）
- **时间跨度**：2月1日 — 2月29日（共29天）
- **覆盖地区**：全国31个省/自治区/直辖市
- **核心指标**：总成交金额 **1,681,390.55 元**，总退款金额 **563,565.17 元**，整体退款率 **33.52%**

## 分析内容

### 一、每日成交金额趋势

按日期聚合买家实际支付金额，观察成交金额在时间维度上的变化趋势。

![每日成交金额](images/每日成交额.png)

**分析结论：**

- 2月上旬（1日—17日）成交金额整体低迷，日均不足 1.5 万元，其中11日—17日连续多日成交接近 0 元
- 2月18日起成交金额爆发式增长，从 2.3 万元快速攀升
- **2月26日达到峰值 228,983.20 元**，较月初增长超 30 倍
- 下旬（18日—29日）日均成交约 12.7 万元，推测与月末促销活动或节后消费回暖有关

### 二、每周成交金额对比

按星期维度聚合成交金额，分析一周内各天的成交分布规律。

![每周成交金额对比](images/订单成交金额平均每周对比.png)

**分析结论：**

- **周五成交最高，达 352,816.68 元**，较周一（180,297.92 元）高出 **95.7%**
- 周二至周六成交均在 28 万元以上，属于销售高峰期
- **周一和周日为成交低谷**，分别为 18.0 万元和 18.4 万元
- 运营建议：在周五加大推广投放力度，周一/周日可适当减少预算或安排复盘

### 三、成交金额地区分布

按省份聚合成交金额，通过中国地图热力图展示各地区消费能力差异。

![成交金额地区分布](images/成交金额分布图.png)

**分析结论：**

- **上海以 264,039.78 元位居第一**，占全国总成交额的 **15.7%**
- TOP5 省份（上海、北京、江苏、广东、浙江）合计贡献 **52.3%** 的成交额
- 高成交地区集中在**东部沿海及一线城市**，经济发达地区消费力显著领先
- 西部地区（西藏、青海、新疆、甘肃）成交额较低，存在较大市场拓展空间

### 四、每日退款金额变化

按日期聚合退款金额，观察退款趋势与成交金额的关联。

![每日退款金额变化](images/退款金额日变化图.png)

**分析结论：**

- 退款趋势与成交趋势高度同步，2月上旬退款金额较低
- **2月25日退款金额达到峰值 70,438 元**，与成交高峰（26日）基本吻合
- 下旬退款金额随成交增长而上升，日均退款约 3.8 万元
- 高成交伴随高退款，需重点关注下旬订单的售后体验和商品质量

### 五、退款金额地区分布

按省份聚合退款金额，结合成交金额分析各地区退款率。

![退款金额地区分布](images/退款金额分布图.png)

**分析结论：**

- 退款金额 TOP5 地区为上海（62,418）、北京（45,941）、广东（45,589）、山东（45,415）、浙江（43,235）
- 主要省份退款率：

| 省份 | 成交金额 | 退款金额 | 退款率 |
|------|---------|---------|-------|
| 上海 | 264,039.78 | 62,418.01 | 23.6% |
| 北京 | 166,448.48 | 45,941.36 | 27.6% |
| 江苏 | 159,359.18 | 43,011.34 | 27.0% |
| 广东 | 147,822.90 | 45,588.70 | 30.8% |
| 浙江 | 141,664.80 | 43,234.80 | 30.5% |
| 四川 | 127,648.15 | 40,299.76 | 31.6% |
| 山东 | 103,917.26 | 45,415.21 | **43.7%** |

- **山东退款率高达 43.7%**，远超其他省份，建议重点排查该地区物流、商品质量或描述不符问题
- 上海退款率最低（23.6%），高成交低退款，用户满意度相对较好

## 快速开始

1. 克隆项目到本地
2. 安装依赖：
   ```bash
   pip install pandas pyecharts matplotlib seaborn
   ```
3. 将数据文件 `tmall_order_report.csv` 放入项目根目录
4. 运行分析脚本：
   ```bash
   python 用户数据分析.py
   ```
5. 脚本将生成交互式 HTML 图表，用浏览器打开即可查看

## 核心发现与建议

1. **时间规律**：周五是成交高峰，周一周日低迷；月末成交爆发，建议在周五和月末提前备货、加大投放
2. **地区差异**：东部沿海贡献过半成交，西部市场潜力大但需针对性运营
3. **退款风险**：整体退款率 33.52% 偏高，山东退款率异常（43.7%），需优先排查
4. **成交退款联动**：退款高峰滞后成交高峰约1天，建议在大促后加强客服和售后跟进
